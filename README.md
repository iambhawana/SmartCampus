SmartCampus – Student Grievance & Complaint Management System

SmartCampus is a web-based student grievance management system designed to help students submit campus-related complaints, track their complaint status, and allow administrators to manage and resolve complaints efficiently.

Features

- Student Registration and Login
- Secure Authentication using JWT
- Submit Campus Complaints
- Automatic Complaint ID Generation
- Track Complaints using Complaint ID
- Admin Dashboard
- Search and Filter Complaints
- Update Complaint Status
- MongoDB Database Integration
- Responsive and User-Friendly Interface

Tech Stack

Frontend: React.js, Vite, CSS

Backend: Node.js, Express.js

Database: MongoDB

Authentication: JSON Web Token (JWT)

Complaint Status

- Pending
- In Progress
- Resolved

Project Structure

SmartCampus/
├── backend/
└── frontend/

Purpose

The main purpose of SmartCampus is to make campus complaint management more transparent, accessible, and efficient by providing a digital platform for students and administrators.
